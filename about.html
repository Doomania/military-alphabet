About MilRef

An independent reference

MilRef is an independent educational project maintained by Doomania. It combines spelling and signaling references with browser-based converters and practice tools. It is not an official NATO, police, aviation, or military publication.

Sources and scope

Where a section has been checked against a primary source, a link appears beside the content. Agency-specific codes must be interpreted in that jurisdiction. General and informal examples are labeled separately. Converters and quizzes are learning tools, not operational certification.

The September 2026 update corrected canonical URLs, official alphabet spelling, timezone coverage, and several unqualified code claims. It is not a claim that every historical or regional statement has received expert review.

Report a correction

Include the page, the disputed statement, and a primary source when possible. Report an issue on GitHub or view the source repository.
